# Reportes de seguridad

Responsable: Ilan Daniele. Contacto privado: **ilan.daniele@gmail.com**, asunto «Reporte de seguridad — Sala de Estudio».

Política pública: https://saladeestudio.com.ar/propiedad-intelectual#seguridad.

## Cómo informar

Indicá la función afectada, fecha aproximada, impacto y pasos mínimos reproducibles con tus propias cuentas y datos ficticios. Omití contraseñas, cookies de sesión, códigos OTP, claves, coordenadas y datos de otras personas. Si una captura contiene información ajena, redactala antes de enviarla.

No publiques vulnerabilidades con datos sensibles en issues, pull requests o chats públicos. Si encontrás acceso a datos ajenos, detené la prueba y comunicá lo mínimo necesario para localizar el problema, sin descargar más información.

Para pruebas que requieran otra intervención, coordiná previamente su alcance con el responsable. Esta política no autoriza pruebas sobre cuentas ajenas, pagos reales, extracción de datos, ingeniería social ni interrupciones del servicio.

## Versiones y seguimiento

La versión mantenida es la desplegada desde `main`. `staging` es un entorno de prueba independiente; esta política no autoriza importar datos reales de producción para realizar pruebas. Las versiones históricas no tienen una rama de soporte propia.

El responsable revisará el reporte, su impacto y la corrección antes de coordinar una divulgación que no exponga datos. No hay un programa de recompensas anunciado ni una promesa de plazo de resolución. Los plazos legales de privacidad no se sustituyen por esta política.

Para consultas de privacidad: https://saladeestudio.com.ar/privacidad#tus-derechos. Para errores de uso: https://saladeestudio.com.ar/sugerencias.
